# 재무·감사 문서의 이미지·텍스트 처리와 오류 검증

졸업연구에서 다뤘던 이미지·텍스트 처리를 재무·회계 문서에도 적용해 보고자 진행한 프로젝트입니다. 공개 재무·회계 문서를 읽고, PDF에서 추출한 표 이미지와 텍스트를 사전학습 ViT·BERT에 입력해 봤습니다.

## 주요 작업

- 공개 사업보고서 PDF의 표를 이미지와 텍스트로 추출하고, 사전학습 ViT·BERT로 각각 특징을 얻었습니다.
- PDF·XLSX에서 질문에 맞는 근거를 검색하고, 회사·기간·표 제목을 추가했을 때의 결과를 비교했습니다.
- 기존 코드의 BERT 학습 연결과 디코더의 미래 토큰 참조를 점검했습니다.
- PDF 병합 셀에서 누락된 회계연도를 복원하고, 같은 모델과 질문으로 검색 순위를 비교했습니다.

## 핵심 결과

| 검증 항목 | 결과 |
| --- | --- |
| BERT 학습 연결 | 캡션 손실만 사용하면 가중치가 변하지 않았고, 대조 손실을 추가하자 학습 신호가 전달됐습니다. |
| 대조학습 | 학습용 16쌍은 모두 맞혔지만 검증 성능은 낮아졌습니다. |
| 회계연도 복원 | 특정 질문의 E5 정답 순위가 원문 검색에서 21위에서 4위로 개선됐습니다. 전체 8개 질문의 Recall@5는 같았습니다. |

학습 연결 수정과 입력 정보 복원의 영향을 각각 확인했습니다. 공시 이미지 실험은 특징 추출까지 진행했으며, 이미지가 검색 정확도에 주는 효과는 추가 검증이 필요합니다.

## 실행 방법

프로젝트 폴더에서 의존성을 설치한 뒤 실행합니다. 첫 실행에는 사전학습 모델 다운로드가 필요할 수 있습니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

# 학습 연결과 문서 추출 문제를 각각 검증합니다.
python verify_model_learning.py
python verify_audit_retrieval.py
```

전체 실험은 `bash run_experiments.sh`로 실행합니다. 결과와 로그는 `results/`에 저장됩니다.
